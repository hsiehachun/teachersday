Google Sheet 後端 Apps Script 設定教學

若您希望將祝福永久儲存到您的 Google Sheet 試算表，請依照以下 3 步驟設定並取得專屬 Web 應用程式網址：

步驟 1：建立試算表並開啟 Apps Script

在 Google 雲端硬碟建立一個新的「Google 試算表」，點擊上方選單的 「擴充功能」 -> 「Apps Script」。

步驟 2：貼上後端程式碼 (Code.gs) 
function doGet(e) {
  var code = (e && e.parameter && e.parameter.code) ? e.parameter.code : "DEFAULT";
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var rows = sheet.getDataRange().getValues();
  var data = [];
  for (var i = 1; i < rows.length; i++) {
    if (rows[i][0] == code || !rows[i][0]) {
      data.push({ name: String(rows[i][1] || ''), word: String(rows[i][2] || '') });
    }
  }
  return ContentService.createTextOutput(JSON.stringify(data))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    var contents = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["活動代碼", "班級座號", "祝福語", "建立時間"]);
    }
    sheet.appendRow([contents.code, contents.name, contents.word, new Date()]);
    return ContentService.createTextOutput(JSON.stringify({ status: "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
步驟 3：部署為 Web 應用程式 (關鍵！)

點擊右上角「部署」->「新增部署作業」-> 選擇種類為「網頁應用程式」：
• 執行身分選擇：我 (您的帳號)
• 誰可以存取：所有人 (Anyone) （極為重要，否則學生無法寫入）
點擊部署並複製結尾為 /exec 的網址貼回活動建立頁即可！
